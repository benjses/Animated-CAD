    Data formats for AniCAD video

    When you are creating an AniCAD video, then you can select one of the following data formats:
  • ".mov"
  • ".mp4" : default option, has the best video quality, but needs autoscaling
  • ".mpeg"
  • ".avi"
  • ".wmv"
  • ".flv"
  • ".gif"

    • At the moment, autoscaling is available for all video-formats. For mp4-videos, this option is always activated, because for this format video creation might fail without a specific image format.
