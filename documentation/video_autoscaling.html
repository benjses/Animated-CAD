    Autoscaling for AniCAD video

    Autoscaling is an option for the AniCAD video fuction.
    When autoscaling is active, then the images of your circuit, which will be created to make the video, are increased in size to match one of the following formats:
  • 320 x 240 : QVGA
  • 480 x 320 : HVGA
  • 640 x 480 : VGA (NTSC)
  • 800 x 480 : WVGA
  • 800 x 600 : SVGA
  • 1280 x 720 : HD
  • 1280 x 1024 : SXGA
  • 1600 x 1200 : UXGA
  • 1920 x 1080 : Full HD
  • 2048 x 1080 : 2K
  • 2560 x 1080 : UWHD
  • 2560 x 1440 : WQHD
  • 2560 x 1600 : WQXGA
  • 3850 x 2160 : UHD-1
  • 4096 x 2160 : 4K

    • At the moment, autoscaling is available for all video-formats. For mp4-videos, this option is always activated, because for this format video creation might fail without a specific image format.
