    What is an ".alib"-file?

    .alib stands for "advanced library". It is a file which describes the different types of electric circuit components.
    The ".alib" files are needed by the AniCAD to find the components' types for each schematic.

    How can I add a library to AniCAD?

    The easiest way to add a library is to copy that ".alib" file into the "libraries" folder under the AniCAD program path.

    How can I create an ".alib"-file?

    You can write an ".alib"-file with a text editor. The language used in ".alib" is an Extensible Markup Language. We have a documentation, which explains how to create Components in ".alib"-files. But if you are a programmer, then it might be easier for you to simply read the the standard component library with a text editor. If you know some XML or HTML and understand some NGspice format and the KiCad component format, then this will be easy for you. If you know parts of that, maybe you will understand the rest by the examples in that library.

    Under which license are the ".alib"-files distributed?
    And under which license may I distribute an ".alib"-file?

    The AniCAD team distributes some ".alib"-files, and we try to distribute them as freely as possible. That means, we like to give you the four Freedoms for our distributed component, as far as possible.

    But sometimes when creating components in ".alib"-files, we need to use texts, which are not distributed this freely. Usually these textparts are Spice-texts of some components, for example if a company produces some OpAmps and provides Spicetext for their components, then they usually use a license that limits modifiactions of that spicetext. In this case, we like to use their spicetext, but of course we can not allow you to modify that text, since it would violate their original license.

    Because of that, the license of each component may be different. So it is good practise to add some license information into the Description of every component.

    We encourage you to also distribute ".alib"-files as freely as possible, but of course you should also pay attention if you are using some texts which are not free.

    Also we are not experts for all types of electric components. Even though we try our best to create and test realistic models for all the components, we can not guarantee that they are flawless. So we present our components AS IS and we disclaim liability for any consequences resulting from using our components.
    When you create a component which you are not absolutely sure about, then you might also present your components the same way. And if you find an error in one of our ".alib"-files, please contact us.
