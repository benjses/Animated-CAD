    Dialogs for creating analyses

    There are two ways, how an electric circuit can be analyzed: Either by simulation or by measuring.
    So AniCAD contains two types of dialogs for starting an analysis: First for simulation, second for loading measured data. Both types are described in an own section below:

    Dialogs for loading data

    In this window the user can load a csv-file into the program. The csv-file shall describe the voltages and the currents of the previously loaded circuit

    The dialog for creating a simulation

    In this window the user can choose the parameters of a simulation: The time settings, the parameters on how to draw currents and to draw voltages, and where to save files of that analysis (if needed)

    Time settings section

    In this first section, you can specify the parameters of the analysis: the maximal(*) timesteps and the end of the simulation.

    These time parameters are specified in seconds. You can write a little s at the end, but you can also skip it.
    You can use m for milli, u for micro, n for nano, p for pico, k for kilo etc: For example
    2u means two microseconds, and
    3.45ms means three point four five milliseconds.
    You can also use the En, where n is a whole number to say "times ten to the power of n"; For example
    2E-6 means two times ten to the power of -3 seconds, which is two microseconds, and
    34.5E-4 means thirty-four point five times ten to the power of -4 seconds which is equal to three point four five milliseconds.

    Out of these parameters, a resulting spicetext is created, wich will be used to create an analysis of the circuit.

    (*) if the option "linearize Timesteps" is NOT chosen, then the timesteps may be shorter than the given timesteps. This is due to the fact that AniCAD uses ngspice to simulate circuits, and ngspice may choose shorter timesteps, see at the ngspice user manual, chapters "1.2.3 Transient Analysis" and "15.3.9 .TRAN: Transient Analysis"

    Parameter drawing section

    In this second section, you can specify how currents and voltages shall be drawn:
    You can define how many significant digits(*) of the parameter-texts shall be shown. If that value is zero, then the parameter texts will not be shown at all.
    You can select one several modes how arrows which symbolize currents shall be drawn via a button for each option. For further information about each option, select the dialog and hover the mouse over the button of that option.

    (*) a significant digit is any digit, except for leading zeros.
    For example if the current of a component is equal to 0.0123456789 Ampere and you have specified the number of significant digits to be 3, then the shown text will be "0.0123 A"

    File settings section

    In this section you can select where the raw-file and the netlist-file of the analysis shall be saved. You can do so, if you would like to keep these files.

    But in the most cases, these files are not interesting for the user, and this section may be skipped. In these cases, the raw-file and the netlist-file are just created for this analysis and will be erased automatically when they are not needed anymore.

    Which wires are drawn?

    If you select no wires drawn, then no wires will be drawn.
    If you select some wires, then the program will draw the wires at some components.
    If you select all, then the program will try to draw all currents. But there are some cases, where the program can not draw some currents.
    For example, if you have multiple paralell wires, then the sum of the current through these wires might be known, but it's not clear, how much of that current flows through each one.
    An other example is if you have connected a wire to flags instead of components. The program does not measure a flag's current (since it is not an electric component, but a helping element for constructing a model on a computer).
    If you want to measure a current through a wire where currents are missing, then you should add a digital shunt resistor
