    Logic statements

    The .alib library format is called "advanced library", because unlike the usual libraries in .lib-format (.lib documentation in english|german), the alib format supports logic statements and variable declarations

    But before learning these details of alib-files in this document below, you might want to read the introduction about how to create alib-files

    Pre-defined variables

    There are variables that can be used directly. These pre-defined variables are:
  • [name] the name of the component
  • [model]the name of the component's model
  • [xpos] the integer value for the x-position of the component
  • [ypos] the integer value for the y-position of the component
  • [rotation] the integer value, 0 or 1 or 2 or 3, describes how many times the component is turned for 90° counter-clockwise
  • [value] the value given by the user. Can be a physical value (e.g. in Ohm for resistors) but can also contain a parameter list or description of the component type for more complex components.
  • [timestep] defines the timestep of the transient simulation
  • [starttime] defines the point of time at which the transient simulation starts, usually 0
  • [endtime] defines the point of time at which the transient simulation ends
  • Also the connections can be used as variable. For example, if the drawing section defines three connections called [D] [G] [S], then these connections can be used in the spice section.

    How to define a variable

    The easiest way to define a variable is to give it a value with one line:
    DEFINE [variable] value
    for example:
    DEFINE [one_point_five] 1.5
    DEFINE [series_number] 52-8.024.12.34
    DEFINE [hotel] trivago!
    DEFINE [param_list] param1=1.5 param2=2k param3=35e-9 param4=4.4E12

    But you can also use define by so-called "AS_"-Functions. These are functions that also define variables, but modify the value in the process. These "AS_"-Functions are:


    AS_UPPERCASE:
    DEFINE [hotel] AS_UPPERCASE OF:[hotel] // changes [hotel] from trivago! to TRIVAGO!.
    AS_LOWERCASE:
    DEFINE [hotel] AS_LOWERCASE OF:[hotel] // changes [hotel] back to lowercase trivago!

    AS_SUBSTRING:
    defines a subsection of the "OF:"string where the parameters FROM:(inclusively) and TO:(exclusively) are numbers. For example: DEFINE [hotel] AS_SUBSTRING FROM:2 TO:7 OF:[hotel] //[hotel]=trivago, extracts a substring between the indexes , here removes the "!" at the end.
    DEFINE [ago] AS_SUBSTRING FROM:4 OF:[hotel] //[ago]=ago, you can omit the TO: in substring, so that the substring goes to the end of the original string.
    DEFINE [tri] AS_SUBSTRING TO:3 OF:[hotel] //[tri]=tri, you can omit the FROM: as well in substring. In this case, FROM: is 0.

    AS_SUBTEXT:
    defines a subsection of the "OF:"string where the optional parameters "FROM:", "AFTER:", "TO:" and "BEFORE:" mark the start and end of that subsection.
    "FROM:" and "TO:" are with the marker, whereas "AFTER:" and "BEFORE:" are without the marker. For example:
    DEFINE [hotel] AS_SUBTEXT BEFORE:!OF:[hotel] //[hotel]=trivago, extracts a substring from start to "!"(exclusively the "!").
    DEFINE [riva] AS_SUBTEXT AFTER:tTO:vaOF:[hotel] //[riva]=riva

    AS_REPLACEMENT:
    DEFINE [fifteen] AS_REPLACEMENT FROM:.TO:OF:[one_point_five] // replaces "." to "", so "1.5"->"15". Watch out for spaces at wrong places!
    AS_FIRST_REPLACEMENT:
    DEFINE [snr] AS_FIRST_REPLACEMENT FROM:.TO:OF:[series_number] // replaces only the first dot to "". So [snr]=52-8024.12.34
    AS_REPLACEMENT_REGEX:
    DEFINE [snr] AS_REPLACEMENT_REGEX FROM:-[0-9]{4}\.TO:-xxxx.OF:[snr] //[snr]=52-xxxx.12.34, here FROM: is a regular expression
    AS_FIRST_REPLACEMENT_REGEX:
    DEFINE [point_five] AS_FIRST_REPLACEMENT_REGEX FROM:[0-9]TO:OF:[one_point_five] //[point_five]=.5, this example removes the first decimal

    AS_WORD_RIGHT:
    DEFINE [second_param] AS_WORD_RIGHT OF:param2 IN:[param_list] //[second_param]=2k, finds out the word after the first occurence of "param2" and ignores the "=" by default.

    AS_VISIBLE:
    DEFINE [one_point_five] AS_VISIBLE // the variable [one_point_five] will be visible by default.*

    AS_INVISIBLE:
    DEFINE [one_point_five] AS_INVISIBLE //the variable [one_point_five] will NOT be visible by default.*
    * "visible by default" means that the visibility is set when loading the circuit, but user can change the visibility of the parameter in the right panel of the main window.

    AS_NULL:
    DEFINE [snr] AS_NULL // erases the variable [snr]

    Numeric functions

    AS_NUMBER:
    DEFINE [second_param] AS_NUMBER OF:[second_param] //[second_param]=2e3, tries to make a number out of a string. If that is not possible, erases the variable.

    AS_CALCULATION:
    DEFINE [two] AS_CALCULATION OF:Math.log10(100) //[two]=2.0 This is a math text interpreter, can calculate functions.
    // It uses the JavaScript Math objects such as: Math.abs(x) or Math.pow(x,y) or Math.log(x) or Math.log10(x)

    AS_MATH_MUL, AS_MATH_DIV, AS_MATH_ADD, AS_MATH_SUB, // math basic functions will create a simple math operation, e.g.
     DEFINE [four_point_five] AS_MATH_MUL OF:[one_point_five] AND:3

    AS_MATH_MIN, AS_MATH_MAX, // math comparison, e.g:
    DEFINE [four_point_two] AS_MATH_MIN OF:[four_point_five] AND:4.2

    AS_MATH_ROUND, // makes the next whole number, e.g.
    DEFINE [four] AS_MATH_ROUND OF:[four_point_two]

    AS_DECIMAL_FORMAT, // makes number in the given decimal form, e.g.
    DEFINE [four_point_20] AS_DECIMAL_FORMAT OF:[four_point_two] FORM:##.##
    // returns 4.20
    AS_MATH_ABS, AS_MATH_SQRT, AS_MATH_POW, //more math functions, e.g.
    DEFINE [one_point_five] AS_MATH_ABS OF:-1.5
    DEFINE [two] AS_MATH_SQRT OF:[four]
    DEFINE [sixteen] AS_MATH_POW AS_MATH_POW OF:[four] AND:[two]    // because 4^2=4*4=16

    Trigonometric functions

    all trigonometric functions have one parameter, marked with OF:
    These functions are:
    AS_DEG_SIN, AS_DEG_COS, AS_DEG_TAN // normal trigonometric functions for degree parameter
    AS_RAD_SIN, AS_RAD_COS, AS_RAD_TAN // normal trigonometric functions for radian parameter

    AS_DEG_ASIN, AS_DEG_ACOS, AS_DEG_ATAN // inverse trigonometric functions giving out degree parameter
    AS_RAD_ASIN, AS_RAD_ACOS, AS_RAD_ATAN // inverse trigonometric functions giving out radian parameter

    AS_DEG_HSIN, AS_DEG_HCOS, AS_DEG_HTAN // hyperbolic trigonometric functions for degree parameter
    AS_RAD_HSIN, AS_RAD_HCOS, AS_RAD_HTAN // hyperbolic trigonometric functions for radian parameter

    Examples:
    DEFINE [one] AS_DEG_SIN OF:90 // because sin(90°)=1.0
    DEFINE [pi] AS_RAD_ACOS OF:1.0 // because acos(1.0)=cos^-1(1.0)=3.141=pi
    DEFINE [baz] AS_RAD_TAN OF:sometext // that will erase the [baz] variable, because "sometext" is not a number.

    Only in animation section: actual value

    In the animation section, you can get the actual currents and actual voltages of pins, and of internally saved values. These values are calculated for each timestep. But they are only calculated, when component animation is activated. To get pin values you can use : DEFINE [act_current] I[outpin] // when outpin is the name of a pin, this gets the actual current in ampere.
    DEFINE [act_voltage] AS_MATH_SUB OF:V[pin1] AND:V[pin2] // voltages are often defined by a voltage difference. That is why this example uses a subtraction of two pin voltages.

    To get internally saved actual values, you can use the AS_ACTUAL statement. First you need to save that value in the spice section, and then you can call its value in the animation section. For example lets assume a component called x_[individual], then you can write a line in the spice .subckt of the component:
    .save v(ctrl)// saves the internal variable "ctrl"

    then you can call it again in the animation section by the following line:
    DEFINE [act_s] AS_ACTUAL OF:x_[individual].ctrl // calls the value of the internal varible ctrl of this component.

    (This example is from the potentiometer in the basic components. You might want to open the 01 basic component.alib library to look at the whole potentiometer description.
