    Frequently asked questions

    Components disappear

    Q: When a schematic is loaded, then a component is shown, but as soon as the simulation starts, this component disappears. Why is that?
    A: This component does not have any connections (distant connections do not count here). Since it has no connections, it is considered irrelevant for the analysis therefor it is removed from the schematic.

    So you can solve this by adding connections to the component in the library.
    Alternatively you can change the settings to keep also Components with zero connections by setting KEEP_ZERO_CONN to 1.
