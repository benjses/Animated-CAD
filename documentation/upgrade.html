    Why upgrade?

    You might want to upgrade your AniCAD, in order to
    make larger circuits and larger analyses,
    get more color themes,
    because the free trial has ended,
    or to support the development of the AniCAD project. We would be happy if you do so.

    How to upgrade

    Either watch this youtube instruction video

    Or go through the following steps:
    1: Click on "Info" -> "upgrade" to open the upgrade dialog. Then copy the identification code from that dialog.
    2: open your internet browser, and go to the upgrade shop at https://www.cirnavsys.com/shop. Select your desired upgrade version.
    3: Paste the identification code into the field. Then go to the checkout of the store and order your upgrade.
    You will recieve an Email from us, which tells you the license code that matches to your identification code, after you have paid for the upgrade.
    4: Copy that license code and paste it into the field in the upgrade dialog. Then click on the set button.
    Done. Your upgraded version is activated at the next start of the program.

    Additional info

    If see a message that tells you that the free trial has ended, then you need to purchase an upgrade to an Hobby or SemiPro or FullPro version. Because these version are not limited in time.

    If you see that message, but in reality the end of the free trial has not yet been reached, then make sure that you have set the correct time on your computer. On most windows computers, you can set it in the menu at the bottom of your screen.
