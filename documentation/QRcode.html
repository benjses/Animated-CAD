    QR codes for circuit files

    You can use QR codes to open the circuit. The Animated CAD has a QR code image creator, so you can save the path of a circuit file, and it has a camera routine to open QR codes so you can open the circuit again via that QR image.

    How to save a QR code

    When you have a circuit opened, then go to
    Output -> save QR code
    A dialog will appear, and will show the options, which text is saved in the image. Click on the "save" button and select where to save the QR image file.

    How to open a QR code

    You can open a circuit from a QR image file, when you open that dialog via
    Input -> Open via QR code
    A dialog window will appear, where you can either activate your computer's camera, or enter a qr image. The program will search the content of the image, and if that content is the path of a circuit file, then you can open it, without having to select the file manually.
