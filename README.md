# Animated-CAD libraries
The Ani-CAD libraries are .alib files, which stands for "advanced libraries". That file format is developed as an advancement from normal libraries such as .lib from qucs or .kicad_lib from kicad.
It is the first programming language for electric components containing editable parameters (by DEFINE statement) and IF-THEN-ELSE-ENDIF statements.
With that you can define your components with all kinds of cases, such as a voltage source with or without a power limit depending on the given parameters, whereas in other languages you would have to define several different power sources for each case.

Therefor ".alib" is (aguably) the best library format.
